Why Agents Need Memory

LLMs are stateless. Every conversation starts fresh.

User says "I'm vegan" → Next turn: steak recommendation

  • Can't remember preferences across sessions
  • Can't learn from past interactions
  • Can't build context over time
  • Can't provide personalization
  • Repeats the same mistakes

Four Memory Types

Inspired by human cognition

Working Memory

Current session buffer

Semantic Memory

Facts, preferences, knowledge

Episodic Memory

Past conversations

Meta Memory

Reflections and insights

Key Benefits

  • Persistent context across sessions
  • Personalized responses
  • Learning from interactions
  • Efficient context management
  • Natural forgetting mechanism

Advanced Features

Memory Decay

7-day half-life exponential decay. Unused memories fade.

Consolidation

Episodes compress to semantic facts during "sleep" cycles.

Reflection

Agent reviews memories to extract patterns and insights.

Importance Scoring

Access frequency boosts memory strength.

Unified Recall

Query all tiers simultaneously with weighted ranking.

Forgetting

Prune low-value memories to prevent bloat.

Memory Decay Formula

Inspired by Ebbinghaus forgetting curve:

strength = base × e^(-λt) × (1 + log(access_count)) base = Initial importance (0.0 to 1.0) λ = Decay rate (7-day half-life) t = Days since creation access_count = Retrieval frequency boost

Memories decay to 50% after 7 days. Frequent access boosts strength.
